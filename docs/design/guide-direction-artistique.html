1. Principes

L'esprit : artisan haut de gamme, chaleureux, sobre. Beaucoup d'air, un seul brun, de l'or en touche.

À faire
  • Un brun (--color-primary) pour l'action, un or (--brand-accent) pour le décor.
  • Boutons pilule, hover = assombrissement seul.
  • Variables :root pour couleurs, espaces, rayons, ombres.
  • Cartes : fond blanc, bordure fine, rayon 12 px, pas de carte dans une carte.
  • Une carte « mise en avant » par bloc, toujours en or.
  • Les grilles de cartes n'ont jamais de carte orpheline (dernière carte impaire en pleine largeur) : problème et solution en 2 colonnes, réassurance en 3.
À ne pas faire
  • Valeur de couleur en dur (hex) ou orange hors palette.
  • Texte doré sur fond clair avec --brand-accent (3:1) : utiliser --brand-accent-text.
  • Soulèvement ou zoom (translate, scale) ou dégradé sur bouton ou carte au survol.
  • Troncature « … » sur un titre ou un nom.
  • Ajouter un 3ᵉ format de bouton.
  • Éditer à la main les pages générées (voir CLAUDE.md).

6. Navigation : barre, burger, sous-menu

La vraie barre est fixée en haut de cette page. Desktop ≥ 992 px : sous-menu au survol (ouverture après 160 ms, uniquement en affichage ordinateur). Mobile ≤ 991 px : burger plein écran ; « Services » ouvre un panneau qui glisse avec un bouton « Retour » — ouverture au toucher seulement, jamais au survol. Redimensionnez la fenêtre pour tester.

  • Lien : .nav-link (soulignement animé au survol et page active)
  • CTA du menu : .menu-cta .btn
  • Téléphone du menu mobile : .menu-tel
  • Code : scripts/sync-header.js (balisage), styles.css (bloc « Navigation Desktop » et media ≤ 991 px), main.js (comportement)

12. Recette : créer ou refondre une page

Checklist à suivre pour que toute page reste dans la même direction artistique.

  1. Page de service ou de ville : copier un dossier de content/pages/ (jamais éditer le .html généré), puis npm run build:pages.
  2. Ordre type d'une page de service : hero → réalisation avant/après → problème → solution + étapes → pourquoi nous choisir → zone → autres services → tarifs → contact → FAQ.
  3. Sections en alternance de fond, chacune avec un .section-header (eyebrow + H2 + chapô).
  4. Un seul bouton primaire visible par écran ; le téléphone en secondaire.
  5. Aucune valeur de couleur en dur ; une seule carte accentuée par bloc (or).
  6. Vérifier à 375 / 768 / 1440 px : aucune carte orpheline, aucun débordement horizontal, aucune cible tactile < 40 px.
  7. npm test, puis mettre à jour docs/changelog.md.
