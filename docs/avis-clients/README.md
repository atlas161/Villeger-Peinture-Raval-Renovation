## Quand l'envoyer

- **Le jour même ou le lendemain de la fin du chantier**, quand le client est encore content du résultat (c'est là
  qu'on a le plus de réponses). Idéal : le **SMS** le jour J, l'**email** le lendemain.
- **Une seule relance**, 5 à 7 jours plus tard, si aucun avis n'est arrivé (SMS « relance » ci-dessous). Pas plus.
- Encore mieux : le dire **de vive voix** à la fin du chantier (« je vais vous envoyer un petit lien pour un avis, ça
  nous aiderait beaucoup ») : le message est attendu et ne finit pas dans les indésirables.

## Règles (Google et PagesJaunes)

- **Jamais de contrepartie** (remise, cadeau, tirage au sort) contre un avis : interdit, Google peut supprimer les avis
  ou pénaliser la fiche.
- Demander à **tous** les clients, pas seulement à ceux dont on est sûr : trier les clients est aussi interdit par Google.
- Ne jamais écrire l'avis à la place du client ni lui dicter le texte.
- Répondre à **chaque** avis sur la fiche (merci + prénom + type de chantier), y compris aux avis négatifs, calmement.

## L'email

### Objet (en choisir un, le 1er est le meilleur)

1. `[Prénom], un petit mot après votre chantier`
2. `Merci pour votre confiance, [Prénom]`
3. `Votre façade est terminée : un petit service ?`

Pourquoi : un objet qui ressemble à un message personnel (prénom, pas de « !!! », pas de « Donnez votre avis ») est
ouvert ; un objet qui sent la pub part à la poubelle.

### À remplacer dans le texte avant chaque envoi

- **`[Prénom]`** (1 fois, dans le titre) → le prénom du client, ou « Madame Martin » si on se vouvoie de loin.
- **`[votre façade]`** (1 fois, 1er paragraphe) → les travaux : « votre façade », « votre toiture », « la peinture de
  vos volets », « l'étanchéité de votre balcon », « la rénovation de votre salon »…

### Comment l'envoyer depuis Gmail (à faire une seule fois, ensuite c'est 30 secondes)

1. Ouvrir `email-demande-avis.html` dans **Chrome** (double-clic sur le fichier).
2. `Ctrl + A` puis `Ctrl + C` (tout sélectionner, copier).
3. Dans Gmail : **Nouveau message** → cliquer dans le corps → `Ctrl + V`. La mise en page, le logo et les boutons
   sont collés.
4. L'enregistrer comme **modèle** : `⋮` (en bas à droite du message) → **Modèles** → **Enregistrer le brouillon
   comme modèle** → « Demande d'avis ».
   *(Si « Modèles » n'apparaît pas : Paramètres ⚙ → Voir tous les paramètres → Paramètres avancés → Modèles →
   Activer.)*
5. À chaque chantier : Nouveau message → `⋮` → Modèles → « Demande d'avis » → remplacer `[Prénom]` et
   `[votre façade]` → mettre l'objet → envoyer.

**Outlook** : même principe (copier-coller depuis Chrome dans un nouveau message), puis l'enregistrer dans
**Mes modèles** ou en **Brouillon** à dupliquer.

> Toujours s'envoyer l'email à soi-même la première fois pour vérifier le rendu sur téléphone.
> Si le logo ne s'affiche pas : c'est que la boîte du client bloque les images ; le texte et les boutons restent
> lisibles sans.

## Les SMS

Écrits **sans emoji ni caractère spécial** : sinon le téléphone découpe le message en 3 ou 4 SMS et les liens
peuvent se casser. Chacun tient en **2 SMS maximum**. Remplacer `[Prénom]`.

**SMS fin de chantier — Google + PagesJaunes (le principal)**

```
Bonjour [Prénom], c'est Stéphane de VPRR. Merci pour votre confiance ! Petite entreprise de Charente, on vit du bouche-à-oreille : votre avis aide d'autres familles à nous trouver (1 min) :
Google : https://g.page/r/CZZJ5Bogt13fEBM/review
PagesJaunes : https://tiny.solocal.com/r/s9roRq
Merci !
```

**SMS court — Google seul** (si le client n'est pas à l'aise avec le téléphone : un seul lien, c'est plus simple)

```
Bonjour [Prénom], Stéphane de VPRR. Merci pour votre confiance ! Si le chantier vous a plu, un petit avis Google nous aiderait énormément (1 min) : https://g.page/r/CZZJ5Bogt13fEBM/review Merci !
```

**SMS relance (5 à 7 jours après, une seule fois)**

```
Bonjour [Prénom], Stéphane de VPRR. Je me permets de vous relancer, sans vouloir insister : si vous avez 1 minute, votre avis compte vraiment pour nous. https://g.page/r/CZZJ5Bogt13fEBM/review Bonne journée !
```

Astuce téléphone : enregistrer ces textes dans les **réponses rapides / modèles** de l'appli Messages (ou dans une
note) pour les coller en deux secondes.

## Priorité Google ou PagesJaunes ?

**Google d'abord** : c'est là que les clients cherchent (« peintre façade Angoulême ») et c'est ce qui fait monter la
fiche dans la carte. PagesJaunes en second. Dans l'email, les deux boutons sont proposés, Google en premier et en plus
visible. Si un client hésite, lui dire : « Google, c'est celui qui nous aide le plus ».

## Signature email

Fichier : [`signature-email.html`](signature-email.html). Logo, filet bronze, coordonnées, services, « devis gratuit
sous 48 h », liens Instagram et « ★ Votre avis » (Google) : chaque mail envoyé fait aussi la demande d'avis, en discret.

**Gmail (ordinateur)** :
1. Ouvrir `signature-email.html` dans **Chrome** → `Ctrl + A` → `Ctrl + C`.
2. Gmail → ⚙ → **Voir tous les paramètres** → onglet **Général** → **Signature** → **Créer** → nom « VPRR ».
3. Cliquer dans la zone de texte → `Ctrl + V` (ne rien retoucher dedans).
4. Juste en dessous : **Pour les nouveaux e-mails** et **Pour les réponses/transferts** → « VPRR ».
   Cocher **« Insérer cette signature avant le texte cité dans les réponses »**.
5. **Enregistrer les modifications** (tout en bas de la page), puis s'envoyer un mail de test.

**Gmail sur téléphone** : l'appli n'accepte que du texte. Soit laisser la signature du téléphone vide (les mails
partent sans signature), soit mettre en texte : `Stéphane Villéger – VPRR – 05 45 91 22 70 – vprr.fr`.

**Outlook** : Paramètres → Comptes → **Signatures** → Nouvelle signature → coller → l'associer aux nouveaux messages
et aux réponses.

Ne pas utiliser la signature dans l'email de demande d'avis : il a déjà sa propre signature et son pied de page.
